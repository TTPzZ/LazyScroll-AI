# LazyScroll MVP Skill

Use this skill when working on LazyScroll AI.

## Goal

Build a local Python desktop app that uses webcam gaze detection to control scrolling.

## Must Use

- Python
- OpenCV
- MediaPipe Face Mesh
- NumPy
- PyAutoGUI
- keyboard
- PySide6 only after core MVP works

## Do Not Use

- cloud APIs
- database
- login
- browser extension
- mobile app
- custom deep learning training
- unrelated AI features

## Development Order

1. Webcam preview
2. Face Mesh
3. Iris tracking
4. Gaze direction
5. Smoothing
6. Scroll engine
7. Hotkey
8. Config
9. Calibration
10. UI
11. Package

## Rule

Only work on the requested phase. Do not skip ahead.
